# Countdown TDD plan

Pomodoro-style countdown timer example.

- [x] initial — shows 25:00 on the named timer
- [x] start — after 1 second elapsed, shows 24:59 (startTime + now derivation)
- [x] pause — remaining time does not decrease while paused
- [x] reset — returns to 25:00
- [x] complete — shows done state when timer reaches zero
